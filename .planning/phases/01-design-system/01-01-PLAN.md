       - `.glass-button` — glass button: extends glass with hover state that increases opacity

    2. **Component Base Overrides (using design tokens):**
       - **Buttons (`.btn`):** Apply `border-radius: var(--radius-md)`, transition on hover, primary button uses `--color-primary` with dark text for contrast, outline variants for secondary
       - **Form Controls (`.form-control`, `.form-select`):** Apply `.glass-input` styles, focus ring uses `--color-primary` glow, placeholder text uses `--color-text-muted`
       - **Range Slider (`.form-range`):** Custom track and thumb using `--color-primary`, dark track background
       - **Tables (`.table`):** Dark header with glass effect, row hover with subtle highlight, `border-radius: var(--radius-md)` on thead, no hard outlines
       - **Cards (`.card`):** Apply `.glass-card` styles by default
       - **Navbar (`.navbar`):** Apply `.glass-nav` styles, brand text uses `--color-text-primary`
       - **Labels & Text:** `.form-label` uses `--color-text-secondary`, headings use `--color-text-primary`

    3. **Icon Styling Base:**
       - `.bi` (Bootstrap Icons) base: `font-size: 1.2rem`, `vertical-align: -0.15em` for alignment with text
       - Icon+text combination: `display: inline-flex`, `align-items: center`, `gap: 0.5rem`
       - Icon in buttons: slightly larger, `font-size: 1.3rem`

    4. **Scrollbar Styling (for dark theme):**
       - Custom scrollbar with `--color-surface-elevated` track and `--color-border` thumb

       - Rounded thumb with `border-radius: var(--radius-full)`
