  <action>
    Redesign `_Layout.cshtml` to apply the dark glass design system. Per D-01, D-02, D-04, D-05, D-07:

    1. **HTML Root Setup:**
       - Add `data-bs-theme="dark"` to the `<html>` tag to activate Bootstrap dark mode globally
       - Keep existing meta tags (charset, viewport)
       - Update `<title>` format to keep current pattern

    2. **CDN Security (per T-01-01 mitigation):**
       - Add `integrity` and `crossorigin="anonymous"` attributes to all CDN `<link>` and `<script>` tags
       - Bootstrap CSS CDN: add SRI hash (use the hash from Bootstrap's official CDN page for the version in use)
       - Bootstrap Icons CDN: add SRI hash
       - Bootstrap JS CDN: add SRI hash
       - If SRI hashes cannot be determined for the exact version, add a comment noting this needs verification and use the latest known hash for Bootstrap 5.3.x

    3. **Glass Navigation Bar:**
       - Replace the white navbar with a glass-effect navigation:
         - Remove `bg-white`, `navbar-light`, `border-bottom` classes
         - Add `glass-nav` class (defined in Plan 01 site.css)
         - Add `navbar-dark` class for light text on dark background
         - Add `position: sticky; top: 0; z-index: 1030` via inline style or class for sticky glass nav
       - Brand area:
         - Replace plain text brand with icon + text: `<i class="bi bi-database-gear"></i>` + "iTransition DataGen" (or similar meaningful icon for data generation)
         - Brand text uses `--color-text-primary`
       - Navigation links (if any): use `nav-link` with glass hover effect
       - Mobile toggler: keep functional, style with glass effect, use `bi-list` icon for hamburger

    4. **Page Structure (Information Architecture per D-05):**
       - Wrap `@RenderBody()` in a `<div>` container with appropriate max-width and padding
       - Add a subtle glass background panel behind main content area to create depth layering
       - Structure: `<header>` (glass nav) → `<main>` (content with optional glass panel) → `<footer>` (minimal, subtle)
       - Remove the outer `<div>` wrapper that exists currently (unnecessary nesting)
       - Remove `style="overflow: hidden"` from `<body>` — this prevents scroll and is harmful

    5. **Footer (Minimal):**
       - Add a minimal footer with subtle text: `© 2026 iTransition DataGen` or similar
       - Style with `--color-text-muted`, small font, centered
       - Optional: thin glass border-top separator

    6. **Script Section:**
       - Keep existing script structure (jQuery, Bootstrap bundle, site.js)
       - Keep `@await RenderSectionAsync("Scripts", required: false)`
