# Roadmap

## Milestone 1: Design System & UI Redesign

### Phase 1: Design System Foundation
**Goal:** Establish a cohesive dark-theme design system with glassmorphism effects, custom color palette, and Material Design-inspired components applied across all pages.

**Requirements:**
- Dark theme with glassmorphism (glass effect) backgrounds
- Custom color palette (not default Material colors — own identity)
- Material Design 3 shape/structure principles for components and layout
- Meaningful iconography that conveys action intent
- Information architecture principles for content organization
- Modern styling with border radius throughout
- Consistent UX flows across all pages

**Requirements:** DS-01 through DS-07
**Plans:** 2 plans

Plans:
- [ ] 01-01-PLAN.md — Design tokens, dark theme override, glass utility classes, component base styles
- [ ] 01-02-PLAN.md — Layout redesign with glass navigation, meaningful icons, IA structure

### Phase 2: Component Library Implementation
**Goal:** Build reusable UI components following the design system — form controls, data table, navigation, buttons, cards.

**Requirements:**
- Glass-effect cards and containers
- Styled form controls (select, range slider, number input)
- Data table with dark theme and glass header
- Action buttons with meaningful icons
- Responsive layout following Material Design grid
